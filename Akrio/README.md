# Admin Practice

A React and Vite admin dashboard for managing products and orders, with a customer-facing store and shopping cart.

## Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown by Vite, then visit `/login` to sign in.

- `npm run preview` - Preview the production build locally.
